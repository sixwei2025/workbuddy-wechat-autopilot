# AI热点选题捕捉系统 V1.5（Tavily驱动版）

## 为什么升级到V1.5

**V1 致命问题**：用 `web_search` 搜小红书/抖音/视频号，搜索引擎根本索引不到这些平台的详情内容，拿回来的全是"讨论这些平台的公众号文章"，数据假、互动数据靠猜。

**V1.5 核心改变**：全面切换到 Tavily 工具栈。经实测验证，Tavily 能抓到：
- ✅ 知乎专栏完整正文（含数据、结构、引用）
- ✅ 公众号文章全文（含竞品对标）
- ✅ 技术博客/新闻站深度内容
- ✅ 微博热搜话题
- ✅ 小红书博主主页标题列表（可做画像分析）
- ⚠️ 小红书笔记详情、抖音/视频号内容仍拿不到——但**爆款信号会外溢到第一层**，通过讨论层捕捉

## 核心工作流（四步）

### 第一步：用户意图确认（30秒内完成）

快速确认三件事：
- **选题方向**：AI工具/智能体/行业趋势/一人公司/副业赚钱（默认：智能体+一人公司，因为这是袁六伟账号定位）
- **时间范围**：默认最近7天（time_range="week"）
- **输出数量**：默认 TOP 5 爆款 + 3 个可立即写的选题

如果用户已明确说了"今天/本周/AI圈什么爆了"，直接跳过确认，执行即可。

### 第二步：分层数据抓取（Tavily 主力）

**关键原则：绝对不再使用 web_search 抓取社交平台内容。全部用 Tavily。**

#### 2.1 深度内容层（主力情报源）

用 `Tavily:tavily_search` 抓知乎+公众号+博客，搜索深度设为 `advanced`，时间范围 `week`：

```python
# 知乎专栏（深度内容）
Tavily:tavily_search(
    query="[主题关键词] AI 智能体",
    include_domains=["zhuanlan.zhihu.com", "zhihu.com"],
    search_depth="advanced",
    time_range="week",
    max_results=8,
    include_raw_content=True  # 抓全文
)

# 公众号转载（竞品对标）
Tavily:tavily_search(
    query="[主题关键词] AI 实战",
    include_domains=["mp.weixin.qq.com", "sspai.com", "36kr.com"],
    search_depth="advanced",
    time_range="week",
    max_results=6
)

# 技术博客 + 海外内容（前沿信号）
Tavily:tavily_search(
    query="[主题关键词] AI agent",
    include_domains=["x.com", "news.ycombinator.com", "reddit.com"],
    search_depth="advanced",
    time_range="week",
    max_results=5
)
```

#### 2.2 信号层（标题即情报）

小红书/微博抓不到详情没关系，抓博主主页即可。博主主页的标题列表本身就是爆款规律：

```python
# 微博热搜话题
Tavily:tavily_search(
    query="AI [主题] 热搜",
    include_domains=["weibo.com", "s.weibo.com"],
    search_depth="advanced",
    time_range="week",
    max_results=5
)

# 小红书头部博主画像（标题列表即信号）
Tavily:tavily_search(
    query="AI 工具 副业",
    include_domains=["xiaohongshu.com"],
    search_depth="advanced",
    max_results=5
)
```

#### 2.3 可选：深度挖取

对第一层返回的 TOP 3 文章，用 `Tavily:tavily_extract` 获取完整正文：

```python
Tavily:tavily_extract(
    urls=["https://zhuanlan.zhihu.com/p/xxx", ...],
    extract_depth="advanced",
    format="markdown"
)
```

### 第三步：异常值识别（真数据 + 启发式）

#### 3.1 可直接读到的真实信号

- 知乎专栏：Tavily 返回的 `score` 字段（相关度，0-1）
- 小红书博主主页：标题旁的数字就是真实点赞数（如"10万+"、"4.3万"、"8821"）
- 微博热搜：话题排名即信号

#### 3.2 启发式异常值判断（当拿不到准确数字时）

**标题信号强度**：
- 含有具体数字的标题（"7天"、"月入3万"、"8个工具"）
- 含有冲突感的标题（"别再"、"错了"、"终于"、"真相"）
- 含有身份标签的标题（"打工人"、"一人公司"、"副业党"）

**内容密度信号**：
- 知乎专栏正文 >3000字 = 深度内容
- 公众号文章含有具体案例/数据/截图描述 = 高价值
- 文章开头 200 字有"钩子"结构 = 爆款基因

**讨论热度信号**：
- 同一话题在多个平台重复出现 = 真爆款外溢
- 竞品公众号已跟进 = 话题已验证
- 技术社区（HN/X）有讨论 = 前沿话题

## 调用 Tavily 的关键参数速查

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `search_depth` | `"advanced"` | 必须用 advanced，basic 太浅 |
| `time_range` | `"week"` | 默认周内，找新鲜热点 |
| `include_domains` | 按层次分组 | 一次只抓一个域名簇 |
| `max_results` | 5-8 | 太多会稀释，太少怕漏 |
| `include_raw_content` | True（深挖时）/ False（扫描时） | 扫描阶段先关，TOP内容再开 |

## 重要原则

1. **禁止使用 web_search 抓取知乎/公众号/微博/小红书/抖音内容** - 这是V1的失败教训
2. **Tavily 是第一选择** - 但要承认它的能力边界：小红书详情、抖音/视频号内容仍拿不到
3. **标题列表即情报** - 不要因为"抓不到全文"就放弃该平台，博主主页的标题规律是金矿
4. **异常值判断要诚实** - 拿不到准确数据时，明确标注"信号强度评估"而非"互动数"
5. **输出必须可执行** - 最后一定要输出"立即可写的3个选题"，不做纯脑暴

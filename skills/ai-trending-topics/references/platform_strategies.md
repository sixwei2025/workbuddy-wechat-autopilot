# 社交媒体平台搜索策略详解

## 知乎搜索策略

### 平台特点
- 用户质量高,深度内容多
- 长文形式,逻辑性强
- 高赞内容有持久价值

### 最佳搜索时机
- 工作日上午(9-11点):职场/效率类内容活跃
- 工作日晚上(20-22点):深度阅读高峰
- 周末:生活方式/技能学习类内容活跃

### 搜索关键词策略

**基础搜索:**
```
"AI工具" site:zhihu.com
"Claude使用技巧" 知乎
"GPT-4实战" 知乎 高赞
```

**进阶搜索(寻找爆款):**
```
"AI" "效率提升" 知乎 赞同>1000
"人工智能" "副业" 知乎 最新
"大模型" "实战" 知乎 收藏>500
```

**话题搜索:**
```
知乎话题: #人工智能# #AI工具# #效率工具#
```

### 爆款内容特征
1. **数据型**:实测数据、对比结果、具体案例
2. **教程型**:step-by-step、可复制、有截图
3. **认知型**:颠覆常识、新角度、深洞察
4. **争议型**:观点鲜明、引发讨论

## 微博搜索策略

### 平台特点
- 实时性强,传播速度快
- 短内容为主,140-300字
- 热搜机制带动话题爆发

### 最佳搜索时机
- 每日12点前:查看热搜榜
- 工作日午休(12-14点):白领活跃时段
- 晚高峰(18-20点):流量最大

### 搜索关键词策略

**热搜追踪:**
```
"AI" "热搜" 微博
"人工智能" "今日" 微博
微博热搜榜 + AI相关话题
```

**大V观点:**
```
"李开复" "AI" 微博
"周鸿祎" "人工智能" 微博
科技大V + AI关键词
```

**话题搜索:**
```
#AI工具推荐#
#ChatGPT使用技巧#
#人工智能发展#
```

### 爆款内容特征
1. **新闻性**:突发事件、行业动态
2. **争议性**:引发讨论、观点碰撞
3. **实用性**:工具推荐、快捷方式
4. **情绪性**:焦虑、兴奋、好奇

## 跨平台搜索技巧

### 时间维度
- **近3天**:最热门、最新鲜的内容
- **近1周**:持续热度、验证价值
- **近1月**:长尾内容、深度文章

### 关键词组合策略

**行业热词:**
- AI、人工智能、大模型、智能体
- Claude、GPT、文心一言、通义千问
- Prompt、提示词、AI绘画

**用户需求词:**
- 效率、赚钱、副业、实战
- 教程、技巧、工具、资源
- 测评、对比、推荐

**情绪触发词:**
- 震惊、颠覆、必看、血泪教训
- 实测、亲测、保姆级、0基础

### 搜索组合公式

```
[平台名称] + [行业热词] + [用户需求词] + [互动数据]

例如:
"知乎 AI工具 实战 高赞"
"小红书 ChatGPT 教程 收藏"
"抖音 智能体 副业 播放量"
```

## 数据抓取要点

### 必须获取的信息
1. **内容基本信息**
   - 标题
   - 发布时间
   - 作者/账号

2. **互动数据**
   - 点赞/赞同数
   - 评论数
   - 转发/收藏数
   - (视频)播放量

3. **内容摘要**
   - 核心观点(前200字)
   - 关键标签/话题
   - 链接地址

### 数据清洗规则
- 排除广告软文(标题含"合作"、"推广"等)
- 排除过时内容(技术/产品已更新)
- 排除低质量内容(纯搬运、无实操)

### 验证机制
- 使用web_fetch获取完整内容
- 交叉验证数据真实性
- 查看评论区反馈质量

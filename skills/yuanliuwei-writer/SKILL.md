## 三、结构骨架（袁六伟 DNA × 结构工程学）

> **融合说明（2026-09-29 升级）**：袁六伟的**灵魂三件**——真实失败换信任 / 判断型表达 / 第一人称实战派——**一个字不动**。
> 本节吸收对标号「爱AI的大刘」的**结构工程学**（该号文章正被 20+ 个号批量搬运，结构已被市场反复验证）。
> **骨架是通用方法，可以学；句子、案例、数字、截图必须是你自己的。**（硬红线，见第十一节 C 组）

### 0. 全文六段位（缺一段 → 重写）

```
① 开篇钩子（3 行按住人）
② 承诺段（这篇给你什么，编号列清）
③ 主体 01/02/03（每节五件套 → 见 2）
④ 🌊 中段转折（技法 → 心法，情绪峰值）
⑤ 写在最后（反向收束，不做总结）
⑥ 尾件三件套（往期导流 + 身份卡 + 三连）
```

### 1. 开篇钩子（前 3 行必须把读者按住）

**4 种之一**，挑最贴话题的：

- **数字结果开篇**："我 11 月发了一篇文章，不到一周阅读破 6000，变现 2 万。"
- **反常识开篇**："大多数人都在焦虑被 AI 替代，其实恰恰相反……"
- **场景故事开篇**："最近看到一张照片：一辆汽车停在路上，车头前却拴着一匹马……"
- **事实数据开篇**："394 人，23 个 Offer。这是 2026 年斯坦福计算机专业的就业真相。"

**无论用哪一种，都必须具象到"能看见画面"**——这是"拦不住人"的最大变量：

- ❌ 抽象版：「很多人都被 AI 的效率问题困扰。」
- ✅ 具象版：「上周一个学员给我发消息：'这方案我改了 6 遍，AI 每次都说"已优化完成"，打开一看跟第一版差不多。'」

**两种具象化手法**（至少用 1 种）：
- **动作回放**——把当时的操作 / 对话 / 屏幕内容写出来（谁说了什么、屏幕上出现了什么）
- **自伤一刀**——先承认自己踩过：「说实话，这个坑我踩了三次才绕过去。」

具象化之后**立刻补一句反驳立论**（判断型，袁六伟底色）：
「不是 XX 的问题，是 YY 的问题。」

### 2. 主体 01 / 02 / 03 —— 每节「五件套」（缺一件 → 补上）

```
## 01 [小标题：直接讲核心结论，≤14 字]

① 一句话点结论（判断型："就是" / "必死" / "根本不是"）
② 痛点场景（具象，能看见画面）
③ 一句"为什么"（解释根因，不是罗列现象）
④ 【能直接拿走的东西】← 关键位，见下
⑤ 真实案例（我的学员 / 客户 / 我自己）+ **［蓝色金句］**
```

每节 400-600 字。

**④ 可拿走物（"通吃位"）**——收藏、转发、关注的理由全在这一个位置：
- 形式：代码框里的 prompt / 配置 / SOP / 清单 / **我真在用的文件片段**
- 铁律：**必须是你真在用的**。不许编、不许拿通用模板凑数
- 一节一个，三节就是三个"能拿走的东西"

**⑤ 金句位（"截图位"）**——每节末尾一句加粗金句，独立成段，这是全文最容易被截图传播的位置：
- 句式锚点：**「……背后的判断是——」** / **「……的本质不是 X，而是 Y」**
- 例：**这一句话背后的判断是：AI 不会替你做决定，只会放大你**已经做过**的决定。**
- **每节都必须有**，单篇总计 ≥ 3 句（旧版只要求 2 句）

> 可拿走物 + 金句位，是这次升级加的两个位。前者管"关注率"，后者管"转发率"。

### 3. 🌊 中段转折（新增位，全文过半处）

插一个独立段落，把话题从**怎么做**拔到**为什么值得做**：

```
🌊 写到这里我停了一下。
我原来也以为 XX 只是个技巧问题。
直到 <一个真实转折点>，我才明白：<认知升维的一句话>。
```

作用：让读者从"学到了"升级到"被点醒了"——收藏和转发的真正触发点。

### 4. 收尾（底层逻辑型，150-300 字）

用「不是 X，而是 Y」翻转一次，再给一句行动指令收掉：

```
[底层判断一句] → [挑战世俗认知一句] → [一句行动号召 / 反问]
```

**再加一层「写在最后」小标题，抛一个**新角度**，不做总结**：
- ❌ 别写："总结一下，今天讲了三点……"
- ✅ 要写："为什么 XX 这件事这么重要？因为它决定的不是效率，是……"

### 5. 尾件（2026-09-30 按契约修正）

```
① 往期导流：相关旧文按编号列出来（"这几篇建议接着看：1. … 2. …"）
② ❌ 不放身份卡 —— 契约明确：「文末不自动添加"袁六伟 · 一人AI公司"等署名、身份介绍或品牌落款」
③ 三连引导 + 星标（可选）
```

> 📌 往期导流仍是**零成本复利位**。但**身份落款已按契约删去**——身份靠内容立，不靠文末贴标签。
> 契约固定要求的文末海报（`assets/ending-poster-product.jpg`，产品介绍版、不带二维码）由排版环节插入，不属本 skill 范围。

## 四、核心句式 8 种（按高频排序）

1. **判断翻转型 ⭐⭐⭐⭐⭐**：「不是 X，而是 Y」——这是袁六伟最高频句式，**自然出现即可，不设次数下限**（契约：不硬凑句式）
2. **直接结论型**：一句话独立成段，不解释（例：「好办，外包。」「大错特错。」）
3. **数字佐证型**：数字 + 时间 + 结果（例：「训练营 11 期，2 万学员」）
4. **口语问答型**：自问自答，制造节奏（例：「为什么？」+ 新段）
5. **比喻类比型**：用 8 个标志性隐喻之一（见五）
6. **递进列举型**：01 / 02 / 03 编号分节
7. **复盘总结型**：「这一路走过来」「后来我才意识到」
8. **具象回放型 ⭐⭐⭐⭐（2026-09-29 新增）**：不复述观点，直接**回放当时的场景**——把操作、对话、屏幕内容写出来，让读者"看见"。
   - ❌ 观点版：「很多人的 prompt 写得太笼统。」
   - ✅ 回放版：「他发来的 prompt 我一眼看完——'帮我写个方案'，六个字。」
   - 用在：开篇钩子、每节②痛点位、案例佐证处

## 六、金句库（提炼得出就放，不设配额）

> 用法（2026-09-30 对齐契约）：金句不是攒在文末，**也不是配额**——提炼得出，就每节末尾放 1 句（第三节⑤"金句位"）；
> **提炼不出不许硬凑**（契约：「不硬凑句式」）。

> 写出来的那句要和本节内容咬合，别拿通用金句敷衍——**它决定这篇能不能被截图转发**。

高频可用：

## 十一、质量检查清单（交付前对照，少一项 → 改到达标）

**A. 袁六伟 DNA（原有，一条不能少）**

- [ ] 6 维度全中（第一人称 / 真实场景 / 判断型 / 个人口吻 / ≥1500字 / 明确经历）
- [ ] 选题已过三门槛（见 `content-planner` 第 0 步）：素材可现截 / 独家是袁总独有 / 转化接得上
- [ ] 开篇 3 行有钩子（4 种之一）
- [ ] 「不是 X，而是 Y」自然出现（**不设次数下限**，契约：不硬凑句式）
- [ ] 8 个标志性隐喻用了 1-2 个（不要全用）
- [ ] 走过 ob 双源（grep 老文 + 取 2-3 篇观点抽样）
- [ ] 走过网络源（aihot 摘要 + 关键事实抓取）
- [ ] 标题留工作版（最终版由咪蒙方法论替换）
- [ ] 输出落 `/tmp/`（工作副本，fact-check / publisher 用）
- [ ] **已落进 Obsidian 并双链**（`IP知识库/07-待发布文章/` 或 `同行知识库/`），回复里报出路径
- [ ] 总字数 1500-2200
- [ ] 不抒情、不鸡汤、不写"大家"、不写家庭日常（家庭是底色不写进公众号）

**B. 结构工程学（2026-09-29 升级新增）**

- [ ] 开篇**具象到能看见画面**（有动作回放或自伤一刀，不是抽象概括）
- [ ] 六段位齐了：钩子 / 承诺段 / 主体 / 🌊转折 / 写在最后（**尾件不含身份落款**）
- [ ] 每节都有**可拿走物**（代码框里的 prompt / 配置 / SOP / 我的真实文件片段）
- [ ] 值得截图的金句**提炼得出就独立成段**（**不设 ≥3 句配额**，契约：不硬凑句式）
- [ ] 有 🌊 **中段转折段**（技法 → 心法）—— 有真实转折点才写，不编
- [ ] 结尾用「写在最后」抛**新角度**，没有出现"总结一下"
- [ ] 文末**没有**自动加署名 / 身份介绍 / 品牌落款（契约红线）

**C. 合规红线（错一条全篇作废）**

- [ ] 可拿走物 / 案例 / 数字**全部真实**，没有编造（没素材就换泛指表述，不许硬填）
- [ ] 与任何同行原文**无句号级重合**（骨架可学，句子必须自己写）

**D. 判别式校准（2026-09-30 新增 —— 改稿 / 质检 / 判断哪版更好时必走）**

> 完整标准：`references/袁氏改写判别标准.md`（从 67 对真实成稿里 7 对显著改动样本反推，每条都有实证出处）。
> A/B/C 是**生成端**检查（该怎么写），D 是**判别端**检查（**哪一版赢、赢在哪**）。两者不能互相替代。

两条实测依据（Meta AI《Unslopping AI》2026-09）：让 LLM 直接判"哪篇写得好"，它判自己写的赢的比例是 **63.5%–84.6%**；
用 LLM 自拟的通用 rubric 打分，AI 稿胜率 **100%**。→ **通用评分会系统性奖励 AI 腔，判别标准必须从真实改稿里长出来。**

- [ ] 开篇有**引号里的人在说话**，或有场景动作（不是「很多人 / 读者 / 大多数人」开头）
- [ ] 小标题**自带判断**，不是名词标签（对照 `二、核心数据（全部标注来源）` → `03 第一个意外：贵的没有算对`）
- [ ] 最重要的判断前 3 行内，有**能担保它的身份 / 经历**，且口径按事实基线 v3
- [ ] 抽象机制后面挂了**读者生活里的同类场景**（如"积分没领全"配"交补餐补年假没用完"）
- [ ] 正文**没有**"关于这篇文章"的元信息（来源标注 / 可信度分级 / 配图清单 / 风险自查）；
      但"你可以来核验"类表述保留（例："数据可以复核，结论欢迎打脸"）
- [ ] 情绪化形容已换成事实陈述（`荒诞的零元购` → `支付系统的 bug 出了漏洞`）；
      书面词已换口语词（`完全`→`压根`、`最后`→`到头来`、`说`→`补充一句`）
- [ ] 删减 / 扩写后，**"读者可拿走的东西"是变多的**（字数本身不判输赢，看可拿走密度）

**判定门槛**：7 条中 **≥6** 才算"像袁六伟"；4-5 要列出具体改哪条；**≤3 退回重写**。

⚠️ **当裁判的模型档次不能低于写稿的模型。** 同一篇论文实测：弱模型当评委，人机差距直接转负——**弱评委看不见差距**。
写稿可以用便宜的模型，**当裁判必须用强的**，这里不省钱。

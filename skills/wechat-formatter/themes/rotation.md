# 按内容选骨架（2026-11-12 起）

🔴 **旧的「按天轮换」已废止**。六套骨架按内容结构、长度、框架灵活选，不是周一到周六轮着用。

| 内容特征 | 骨架 id | 中文名 | 开篇形态 |
|---|---|---|---|
| 长教程 / 清单 / 工具盘点 / 高密度信息、图多 | `magazine-card` | 汇芯红·杂志卡 | 杂志快讯封面 + 横向目录 |
| 深度分析 / 观点 / 力量感话题 | `classic-edit` | 汇芯红·经典编辑 | 引言卡 + 编号章节 |
| 设计 / 科技评论 / 短观点 | `minimal-line` | 汇芯红·极简细线 | 细线金句 |
| 深度随笔 / 情绪性文字 / 图少 | `zen-space` | 汇芯红·禅意留白 | 衬线大字 |
| 测评 / 工具对比 | `ticket` | 汇芯红·票据 | 门票封面 |
| 案例复盘 / 系统性说明 | `journal` | 汇芯红·内刊手记 | 内刊头图 |

判定顺序：信息密度与图量 → 有无清单/代码块 → 情绪浓度。
同日多篇才考虑换一套，不为换而换。一篇只用一套，不混搭。
⛔ `zen-space` 对教程/清单是弱契合，组件库自己写明「建议换主题」。
⛔ 转换器 `--theme auto` 仍按星期，只是兜底；正式稿显式传 id。
⛔ 转换后必跑 `apply_theme_shell.py` 装配主题专属组件，否则校验拦下。

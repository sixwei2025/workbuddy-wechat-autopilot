# public-safe 检查清单

发布前逐项检查。

## 身份与背书

- [ ] 没有编造袁六伟身份、头衔、课程成绩、客户数量、学员数量。
- [ ] 如需介绍，只使用确认过的公开安全版本。
- [ ] 没有暗示未授权官方合作或平台背书。

## 结果与收益

- [ ] 没有保证涨粉、保证成交、保证收益。
- [ ] 没有把个案包装成普遍结果。
- [ ] 收益、阅读、客户结果都有来源或已做模糊化处理。
- [ ] 避免“躺赚、稳赚、暴富、无脑复制”等高风险表达。

## 来源与版权

- [ ] 没有照搬别人完整文案。
- [ ] 外部事实有可回溯来源。
- [ ] 截图已去除隐私信息。
- [ ] 第三方 IP、人物、品牌、客户资料没有被冒用成商业成果。

## 平台与敏感内容

- [ ] 不碰政治敏感、意识形态冲突、重大公共争议。
- [ ] 法律、医疗、金融等专业内容只做经验分享，不替代专业建议。
- [ ] 不攻击具体平台、公司或个人。
- [ ] 不发布可能导致主账号风险的争议内容。

## 文章质量

- [ ] 标题有吸引力，但不标题党。
- [ ] 开头 300 字内讲清读者为什么要看。
- [ ] 中间有真实材料支撑，不是纯观点空转。
- [ ] 结尾有自然承接，不硬推销。
- [ ] 配图清单已经准备好。

## 🔴 第 0 步：三门槛判定（2026-09-30 拍板 · 缺一不写）

> 来源：对标「爱AI的大刘」方法论提炼。**本 skill 的唯一硬闸门**——模式 A / 模式 C 动工前必须先过。
> 低于标准的选题，不进之后任何环节：不写、不排、不配图、不做封面。

| 门槛 | 具体要求 | 过不了怎么办 |
|---|---|---|
| **素材门槛** | 有没有**能现截真实界面截图复现**的场景？严守配图铁律：真实截图为主力，长文 8-14 张、截图占多数、现截现用，禁用旧图凑 | 换选题，或先去把场景真跑出来 |
| **独家门槛** | 有没有**只有袁总才有**的东西：一手账单、失败对照、内部流水线、创建者视角的设计取舍 | 竞品也给得出 → 撞脸，弃 |
| **转化门槛** | 能不能**顺到商单交付或课程**，不是看完就走 | 只能做成爽文 → 不写 |

**必须在每条选题下输出判定结果：**

```
素材 ☐过 ☐不过 —— 可截：<具体哪个界面 / 后台 / 转账记录>
独家 ☐过 ☐不过 —— 独有物：<一手账单 / 失败对照 / 内部流水线 / 创建者视角>
转化 ☐过 ☐不过 —— 承接点：<训练营 / 星球 / 商单交付>
三门槛结论：写 / 不写
```

⚠️ **三条全过才往下走。任何一条空着，等于没判。**
⚠️ **本文件是三门槛的唯一权威口径。** 历史旧版（素材门槛＝"有没有一手素材"、独家门槛＝"他给不给得出"）**已于 2026-09-30 废止**，以本表为准。

## 模式A：内容日历规划

### 输入
- 时间跨度（默认：本周7天）
- 已定选题（可选）
- 近期热点（可调用ai-trending-topics先搜集，或直接用用户提供的素材）

### 执行步骤

**Step 1：盘点现有素材**
询问或推断：
- 用户手头有哪些已写/半写的内容？
- 近期有什么业务节点（训练营开课、新品发布、大事件）？
- 上周/上期发了什么（避免重复话题）？

**Step 2：搜索时效性热点**（如用户未提供）

优先使用 Tavily MCP（`tavily-search`，`days=2`）搜索48小时内热点，备选 web_search：
```
AI智能体 一人公司 最新
AI副业 赚钱 本周热点
OpenClaw Claude 新功能
```

**Step 3：生成内容日历**

输出格式：

```

━━━━━━━━━━━━━━━━━━━━
周一 | 干货实战
标题：[标题]
核心：[一句话说清楚这篇讲什么]
钩子：[开篇用什么角度吸引人]
预计阅读：[高/中/低]
━━━━━━━━━━━━━━━━━━━━
周三 | 商业洞察
...
━━━━━━━━━━━━━━━━━━━━

...
━━━━━━━━━━━━━━━━━━━━

⚡ 本周备用选题（如有突发热点可替换）
1. [选题]
```

## 模式B：标题工厂

### 适用场景
- 已有选题/草稿，需要批量生成标题
- 已有标题，需要优化或出变体
- 测试不同风格看哪个更适合

### 执行步骤

**Step 1：理解核心内容**
从用户提供的选题/草稿中提炼：
- 核心价值主张（读者读完能得到什么）
- 目标读者痛点
- 最强的数据/案例/反常识点

**Step 2：套用标题公式矩阵**

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字型 | X个/X步/X万 + 动词 + 结果 | "3步用AI做出月入10万的工作流" |
| 疑问型 | 为什么/凭什么/怎么可能 + 颠覆认知 | "为什么聪明人都在用AI做副业，而不是学AI？" |
| 对比型 | [普通人] vs [做到的人] + 差别在哪 | "同样用ChatGPT，他月入5万，你只是省了点时间" |
| 案例型 | [具体人物/公司] + [做了什么] + [结果] | "一个人+6个AI员工，他一年服务了80家企业" |
| 利益型 | 直接说出读者得到什么 | "这套AI写作系统，让我每天节省4小时" |
| 悬念型 | 设置信息缺口 | "AI行业有个秘密，99%的人都不知道" |
| 预警型 | 如果你还在XXX，就晚了 | "还在手工做内容的人，已经输在起跑线了" |
| 颠覆型 | 反常识 + 解释 | "我劝你不要用AI做自媒体——除非你有这个" |

**Step 3：输出标题方案**

每个选题输出 **6-8个标题变体**，按类型标注，并给出推荐理由：

```
📌 选题：[核心主题]

【推荐首选 ⭐】
标题：[标题]
理由：数据钩子强，切中创业者赚钱焦虑

【备选2】
标题：[标题]
理由：适合发朋友圈，转发率更高

【备选3】（适合热点借势时用）
...

💡 发布建议：
- A/B测试推荐：[标题1] vs [标题2]
- 最佳发布时间：[工作日晚8-10点 / 周末上午]
```

## 模式C：选题决策

### 适用场景
用户没有明确选题，需要从0到1确定"这期写什么"。

### 执行步骤

**Step 1：快速盘点**（1-2个问题，不超过2个）

问：
1. 最近有什么让你印象深刻的事/案例/工具？（业务里的、看到的）
2. 上期发了什么？有什么读者反馈？

**Step 2：Tavily多平台异常值搜索（48小时内）**

优先使用 Tavily MCP 工具（`tavily-search`）并行搜索以下平台，捕捉过去48小时内与账号人设强相关的高互动内容：

搜索关键词组（每组至少搜一次）：
```
AI智能体 一人公司 site:xiaohongshu.com
AI副业 赚钱 智能体 site:zhihu.com
OpenClaw AI agent 一人公司
AI工具 效率 副业 公众号
```

搜索参数建议：
- `days=2`（只要48小时内）
- `max_results=10`
- `search_depth=advanced`

**异常值判断标准（快速筛选）：**
- 知乎：赞同数 >500 或 评论数 >100
- 小红书：点赞 >500 或 收藏 >300
- 公众号：能被Tavily抓到且发布<48小时（本身就是异常值信号）
- X（推特）：转发 >200 或 点赞 >1000（中文AI创业圈）

**从搜索结果中提炼3个维度：**
1. 什么话题正在引发共鸣？（高互动的情绪/观点）
2. 什么问题读者在反复问？（评论区高频问题）
3. 什么内容格式在跑量？（列表/案例/观点/测评）

**Step 3：生成选题候选池**

结合Tavily搜索结果 + 以下维度，出5-8个选题候选：

1. **热点借势**：Tavily搜到的48小时异常值内容，能借什么势？
2. **业务结合**：近期项目/训练营/客户案例能出什么干货？
3. **常青话题**：账号核心话题中哪些还没写深、没写透？
4. **读者问题**：粉丝常问的问题，能系统化回答的？

**Step 4：评分 + 推荐**

每个候选选题用三个维度评分（1-5星）：

| 选题 | 时效性 | 账号契合度 | 写作难度 | 综合推荐 |
|------|--------|-----------|---------|---------|
| [选题1] | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 低 | **强烈推荐** |
| [选题2] | ⭐⭐⭐ | ⭐⭐⭐ | 中 | 备选 |

标注每条选题的**素材来源**（来自Tavily哪个平台的异常值 / 自身业务 / 常青话题），方便判断写作难度。

**Step 5：对推荐选题直接进入模式B，输出标题**

---

## 输出原则

1. **直接给答案**：不问"你想要什么风格"——直接出方案，用户觉得不合适再调
2. **可执行优先**：每个选题都要有明确的"核心论点"，不能只有一个模糊方向
3. **配合流水线**：选题确定后，主动提示"需要我继续帮你写正文吗？"（衔接wechat-formatter）
4. **标题要大胆**：公众号标题要有张力，宁可稍微夸张也不要平庸

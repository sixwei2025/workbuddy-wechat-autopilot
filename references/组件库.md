正文主体字色保持深灰/近黑，绝不整段染红；每篇 3–6 处。主色以当篇骨架的 `themes/palette.md` 为准（汇芯红 `#C8102E`）。

## 平台红线（组件 HTML 必须遵守）

- 禁止：`<style>` / `<script>` / `<div>`、`class` / `id` 属性、`position:fixed/absolute/sticky`、
  `float`、`@media` / `@keyframes`、`display:grid`、CSS 变量、外部字体 / CSS 链接。
- 必须：样式全部内联 `style`；用 `<section>` / `<p>` / `<span>` / `<strong>` / `<img>`。
- 可用：`display:flex`（有限）、`border-radius`、`box-shadow`。
- **禁用：`linear-/radial-/conic-gradient`**（2026-11-02 乱码硬闸，浅装饰改纯色，如 `#FCA5A5`）。

## 组件 1 · 引言卡（quote-card）

**触发**：`:::quote` 容器，内容为一句金句。
**用途**：锚点层最强强调，深色底白字，全文 ≤ 5 处。

```html
<section style="margin:24px 20px;padding:18px 20px;background:#B92F27;border-radius:10px;">
<p style="margin:0;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;font-size:17px;line-height:1.8;color:#ffffff;font-weight:700;">客户买的从来不是软件，是「终于有人把这件事给我弄明白了」。</p>
</section>
```

## 组件 2 · 数据卡（stat-card）

**触发**：`:::stat` 容器，第一行 `大数字 | 说明文字`。
**用途**：突出关键数据（成本、收益、倍数），用 flex 横向排布。

```html
<section style="margin:20px;padding:18px;background:#FAFAFA;border:1px solid #EDEDED;border-radius:10px;display:flex;align-items:baseline;">
<p style="margin:0;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;font-size:34px;font-weight:800;color:#C7352D;">1-2<span style="font-size:16px;">元</span></p>
<p style="margin:0 0 0 12px;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;font-size:14px;color:#666666;line-height:1.6;">单条聊天记录视频的 AI 成本，外包要几百到几千</p>
</section>
```

## 组件 3 · 标签卡（tag-card）

**触发**：`:::tag` 容器，空格或逗号分隔的标签词。
**用途**：分类 / 关键词收口，药丸样式。

```html
<section style="margin:16px 20px;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;">
<span style="display:inline-block;background:#FDF4F3;color:#C7352D;font-size:13px;font-weight:700;padding:4px 12px;border-radius:20px;margin:0 8px 8px 0;"># 一人公司</span>
<span style="display:inline-block;background:#FDF4F3;color:#C7352D;font-size:13px;font-weight:700;padding:4px 12px;border-radius:20px;margin:0 8px 8px 0;"># 排版</span>
<span style="display:inline-block;background:#FDF4F3;color:#C7352D;font-size:13px;font-weight:700;padding:4px 12px;border-radius:20px;margin:0 8px 8px 0;"># 品牌红</span>
</section>
```

## 组件 4 · 结语卡（end-card）

**触发**：`:::end` 容器，内容为结语副标题。
**用途**：收尾锚点，深色底居中，全文仅一处。

```html
<section style="margin:28px 20px;padding:20px;background:#1F1F1F;border-radius:12px;text-align:center;">
<p style="margin:0;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;font-size:18px;font-weight:800;color:#C7352D;letter-spacing:2px;">END</p>
<p style="margin:8px 0 0;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;font-size:14px;color:#CCCCCC;line-height:1.7;">今天这套排版，主体唯一、文字不堆砌</p>
</section>
```

## 组件 5 · 对比卡（compare-card）

**触发**：`:::compare` 容器，两行 `左标题 | 左内容` 与 `右标题 | 右内容`。
**用途**：旧做法 vs 新做法、A vs B 并排，用 flex 两列（禁用 grid）。

```html
<section style="margin:20px;display:flex;gap:12px;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;">
<section style="flex:1;padding:14px;background:#FAFAFA;border:1px solid #EDEDED;border-radius:10px;">
<p style="margin:0 0 6px;font-size:14px;font-weight:800;color:#C7352D;">旧做法</p>
<p style="margin:0;font-size:13px;color:#666666;line-height:1.7;">整段染红，重点被淹没</p>
</section>
<section style="flex:1;padding:14px;background:#FDF4F3;border:1px solid #F1D9D6;border-radius:10px;">
<p style="margin:0 0 6px;font-size:14px;font-weight:800;color:#B92F27;">新做法</p>
<p style="margin:0;font-size:13px;color:#666666;line-height:1.7;">红只点在锚点，眼睛有落点</p>
</section>
</section>
```

## 组件 6 · 步骤卡（step-card）

**触发**：`:::step` 容器，内部用 `1.` `2.` `3.` 有序列表。
**用途**：操作指引、流程分步，编号圆点用品牌红。

```html
<section style="margin:16px 20px;font-family:'PingFang SC',-apple-system,BlinkMacSystemFont,'Helvetica Neue',Arial,sans-serif;">
<section style="display:flex;align-items:flex-start;margin-bottom:10px;">
<span style="flex:none;width:26px;height:26px;background:#C7352D;color:#FFFFFF;font-size:14px;font-weight:800;border-radius:50%;text-align:center;line-height:26px;margin-right:12px;">1</span>
<p style="margin:0;flex:1;font-size:15px;color:#333333;line-height:1.7;">打开排版预览，点右上角复制</p>
</section>
<section style="display:flex;align-items:flex-start;">
<span style="flex:none;width:26px;height:26px;background:#C7352D;color:#FFFFFF;font-size:14px;font-weight:800;border-radius:50%;text-align:center;line-height:26px;margin-right:12px;">2</span>
<p style="margin:0;flex:1;font-size:15px;color:#333333;line-height:1.7;">到公众号编辑器 Ctrl/⌘+V 粘贴</p>
</section>
</section>
```

## Markdown → 组件映射表

| Markdown 写法 | 生成组件 |
|---------------|----------|
| `:::quote` 金句 `:::` | 引言卡 |
| `:::stat` 大数 \| 说明 `:::` | 数据卡 |
| `:::tag` 词1 词2 词3 `:::` | 标签卡 |
| `:::end` 副标题 `:::` | 结语卡 |
| `:::compare` 左\|左内 / 右\|右内 `:::` | 对比卡 |
| `:::step` 1. … / 2. … `:::` | 步骤卡 |
| `## 标题` | 小标题（编号红块，沿用原逻辑） |
| `> 引用` | 重点条（浅红底左竖条） |
| `- 项` | 红点列表 |
| `**词**` | 品牌红加粗 |

## 模板骨架（文章装配顺序）

1. 开头引言段（≤2 段，深字）
2. `## 01` 小标题 + 正文
3. 按需插入 `:::quote` / `:::stat` / `:::compare` / `:::step` / `:::tag`
4. 结尾 `:::end` 收尾（可选，替代纯文字结语）
5. 固定文末海报（由 layout-publisher 插入，不在此库）

**一条文章只用品牌红这一套组件**，不混入其它配色体系。
